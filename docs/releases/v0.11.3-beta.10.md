This beta brings the workspace, model, native-service and connected-source changes
into one qualified frontend revision for CLIO's next product beta.

### NDP datasets and endpoints
Browse publishers and resources, use private device sign-in and retain selected
data as Sources. Connect to an existing Endpoint over a URL or saved SSH profile,
review operations and capture bounded stream responses. Protected live Kafka
access still depends on the account and Endpoint authorization.

### Interactive artifacts and diagrams
Generated HTML can use WebGL, while HTML/SVG viewers adapt to their content and
theme. Pele diagrams support readable docked layouts, standalone exports and
explicit links to workspace folders. Inline math renders in chat and documents.

### Workspace access and attention
Edit folder paths directly, browse additional permitted folders and approve
requested external access. The attention pager retains answers while navigating;
required question bundles submit together. Large pastes can become attached Sources.

### Models, native services and updates
Context limits are visible and filterable. The picker opens progressively, and
activity distinguishes waiting, reasoning and goal judging. Runtime limits can
be configured, native services include AMD options, and one product update keeps
Desktop and its runtime together.
